# Servicios electromecánicos

Este proyecto es una página web sencilla para presentar servicios de instalaciones eléctricas, mantenimiento y automatización.

## Objetivo

Aplicar el uso de Git y GitHub mediante ramas, commits, repositorio remoto, Pull Request y publicación con GitHub Pages.

- HTML
- CSS
- JavaScript
- Git y GitHub
